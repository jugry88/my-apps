# 봉사 보고

파이오니아 봉사 시간을 달력에 기록하고 월·연 합계를 보는 개인용 앱.

- 주소: https://jugry88-apps.netlify.app/service/
- 처음 만든 날: 2026-11-14

## 기능

- 달력에서 날짜를 누르면 시간과 메모 기록: 숫자를 눌러 직접 입력, 또는 +0.5 / +1 / +5 / +10 버튼을 누를 때마다 더해짐(30분 단위로 맞춤), −/+ 0.5, 0으로 되돌리기. 하루 상한 없음(지난달 합계를 한 날짜에 한꺼번에 입력 가능)
- 월 합계와 목표(기본 50시간) 진행 막대, 남은 시간, 이번 달 남은 날 기준 하루 필요 시간
- 봉사 연도(9월 1일 ~ 다음 해 8월 31일) 합계와 목표(기본 600시간), 지금까지 목표 대비 앞섬/모자람, 남은 달 매달 필요 시간
- 봉사 연도 12개월 막대(누르면 그 달로 이동), 달력 좌우로 밀어 달 이동
- 📋 보고 문구 복사: "2026년 11월 봉사 보고 / 시간: ○○시간 / 성서 연구: ○"(그달 연구 기록이 있는 연구생 수)
- 📒 재방문·연구 탭(홈 위): 사람별 카드(재방문/성서 연구), 방문할 때마다 날짜+메모를 이어서 기록하고 회차가 쌓임(1회, 2회…), 마지막 방문일·내용 한눈에, 종류 바꾸기(재방문→성서 연구), 이번 달 방문 횟수·연구생 수 요약
- 날짜 창에서 바로 재방문·연구 기록: 만난 사람을 고르거나(새로 등록 시 이름·종류·주소) 나눈 내용을 적으면 재방문 탭의 그 사람 기록에 그 날짜로 이어서 쌓임. 저장 버튼을 누르면 함께 저장됨
- 사람마다 주소(📍, 네이버 지도로 열기)와 연락처·만나기 좋은 때를 따로 기록
- ⚙️ 설정: 월·연 목표 변경, 백업 파일 저장/불러오기, 전체 지우기
- 기록은 그 기기 브라우저에만 저장(서버 없음). 30일 넘게 백업하지 않으면 백업 안내 표시
- 홈 화면에 추가하면 앱처럼 열리고, 인터넷이 없어도 열림(sw.js)
