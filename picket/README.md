# 모션 피켓

태블릿·휴대폰을 피켓처럼 들고 안내할 때 쓰는 움직이는 안내 화면.

- 공개 주소: https://motion-picket.netlify.app
- 처음 만든 날: 2026-11-07
- 파일: `index.html` 하나에 모든 기능이 들어 있음 (외부 파일 없음)

## 기능

- 기본 멘트 4개: 움직여주세요 · 인터뷰 대기줄 · 천천히 · 환영합니다
- 멘트 직접 입력: 문구, 보조 문구, 글씨 색(주황·파랑·보라·검정·알록달록), 움직임(둥실·화살표·줄서기·천천히·축하·깜빡임)
- 화면을 한 번 톡 치면 메뉴: 전체 화면 · ↻ 화면 돌리기 · 화살표 방향 · 멘트 수정 · GIF 저장 · 처음으로
- ↻ 화면 돌리기: 누를 때마다 화면이 90도씩 회전(0°→90°→180°→270°), 기기의 회전 잠금과 상관없이 쓸 수 있음. 마지막 회전 상태는 그 기기에 기억됨
- GIF 저장: 기기(지금 이 기기·아이패드·아이폰·갤럭시)와 방향(가로·세로)에 맞춰 화면에 꽉 차게, 초당 20장
  - 아이폰·아이패드: 공유 창에서 '이미지 저장' → 사진 앱
  - 안드로이드: 바로 다운로드 → 갤러리 'Download' 앨범
- 카카오톡 내장 브라우저로 열면 자동으로 기본 브라우저로 넘김
- 아이폰: 사파리 '홈 화면에 추가'로 열면 주소창 없는 전체 화면
- 배경: 로고 색감(주황·노랑·보라·하늘·파랑)을 옅게 번지게 한 배경, 로고 이미지는 쓰지 않음
